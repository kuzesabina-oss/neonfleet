# Neon Fleet — «Морской бой»

**Опубликованный проект:** https://neonfleet-9c3jc6fn.manus.space/

Neon Fleet — браузерная sci-fi-версия классического «Морского боя» с неоновым интерфейсом, уровнями, аккаунтами, монетизацией и режимом игры с другом.

## Реализованные функции

- Классический бой на поле 10×10 против компьютера.
- Флот: линкор, крейсеры, эсминцы и катера.
- Ручная и случайная расстановка кораблей.
- Проверка границ и запрет соприкосновения кораблей.
- Попадание даёт дополнительный выстрел; промах передаёт ход ИИ.
- Два уровня сложности: случайная стрельба и режим «охота».
- Аккаунт через Manus OAuth с серверной сессией.
- Сохранение профиля, побед, поражений, точности и прогресса.
- Открытие следующего уровня через 24 часа после победы.
- Demo PRO-подписка на 30 дней: открывает уровни сразу и убирает ожидание.
- Серверный кошелёк и награды за победы.
- Магазин косметических предметов за игровые монеты.
- Поиск пользователей по игровому имени и заявки в друзья.
- PVP-комната по коду: подключение второго игрока, отправка флотов и серверная проверка ходов.
- Адаптивный интерфейс для desktop и mobile.

## Технологии

- HTML5 и семантическая разметка.
- CSS3: responsive layout, CSS Grid/Flexbox, неоновая sci-fi стилистика.
- Vanilla JavaScript без frontend-фреймворка.
- Node.js HTTP server.
- MySQL через пакет `mysql2`.
- Manus OAuth и cookie-based серверная сессия.
- Docker для production-публикации.
- Managed Web Dev deployment и HTTPS.

## AI-инструменты

- **Manus AI** — проектирование интерфейса, разработка HTML/CSS/JavaScript, реализация игровой механики, серверного API, базы данных, OAuth, PVP-комнат и подготовка публикации.
- **Manus Web Dev** — инициализация проекта, настройка серверного контейнера, MySQL, checkpoint и deployment.

## Запуск локально

Требуется Node.js 22+ и MySQL. Сервер получает следующие переменные окружения:

```text
DATABASE_URL
MANUS_PROJECT_ID
MANUS_OAUTH_PORTAL_URL
MANUS_OAUTH_API_URL
MANUS_JWT_SECRET
```

Установка и запуск:

```bash
npm install
npm start
```

Приложение слушает порт `3000` или значение переменной `PORT`.

## Проверка Demo PRO

Реальная оплата банковской картой в учебной версии не подключена. В аккаунте доступна явно обозначенная кнопка **«Активировать Demo PRO на 30 дней»**, чтобы проверяющий мог проверить механику подписки и мгновенное открытие уровней без оплаты.

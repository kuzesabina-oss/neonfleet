# Neon Fleet

Интерактивный «Морской бой» с уровнями, аккаунтами, друзьями, кошельком, магазином, подпиской и матчами по коду.

## Возможности

- Manus OAuth для настоящего аккаунта и серверной сессии.
- MySQL для пользователей, друзей, прогресса, покупок и матчей.
- 24-часовая задержка следующего уровня после победы.
- Demo PRO-подписка на 30 дней: открывает все уровни сразу.
- Кошелёк: награды за победы и покупки косметических предметов.
- Друзья: поиск по игровому имени и заявки.
- Multiplayer: создание комнаты, подключение по коду, серверная проверка хода.

## Локальный запуск

```bash
npm install
npm start
```

Нужны `DATABASE_URL`, `MANUS_PROJECT_ID`, `MANUS_OAUTH_PORTAL_URL`, `MANUS_OAUTH_API_URL` и `MANUS_JWT_SECRET`.

## Важно для проверки

Оплата подписки на внешнюю карту не подключена: в интерфейсе есть явно обозначенная **Demo PRO activation**, чтобы проверяющий мог открыть все уровни без платежа. Реальное списание денег не выполняется.
